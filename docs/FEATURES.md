# GUI 功能清单(版本化记录)

**目的**:DSH GUI 从「纯封装」逐步长出产品功能,本表是唯一权威清单,
供跨项目统筹(与 dsh-agent-core 的合并规划)和版本管理使用。

**规则**:GUI 侧每次新增/变更/移植功能,必须在此登记;
登记时机 = 功能合入 main 时;来源列标明功能出自哪里。

## 类型图例

- **封装**:对 DSH 内核的包装能力(壳的本职)
- **新增**:本仓库开发的产品功能
- **移植**:自 dsh-agent-core(云端)移植的能力
- **规划**:方向已定、尚未开发
